# Getting Started with NI LabVIEW and Instrument Control

Automated Test training by Thetic Engineering Ltd.

## Purpose

This repository contains the course materials required to complete the exercises and homework.  The slides, recordings, and other course materials are not available in a repo and remain proprietary, copyright to Thetic Engineering Ltd.

## Repo Layout

| Folder                           | Purpose                                                                                    |
| :------------------------------- | ------------------------------------------------------------------------------------------ |
| [documentation](/documentation/) | Test files which relate to the setup of the course's Windows installations.                |
| [firmware](/firmware/)           | Firmware files to convert a Raspberry Pi Pico into an Serial (RS232) Instrument Simulator. |
| [project](/project)              | The LabVIEW project used during the course, in version LabVIEW 2024Q3.                     |
| [resources](/resources)          | Images and other files required to render markdown in this repo.                           |

## How to Use this Repository

The default branch of this repo is `main` with the Thetic actively developing in `dev`.  To use the version of the files that matches your version of the course, see the `version` tag on your student manual and download the equivalent ZIP from the `releases` section of this repo.  For example, course `v_20250228_1` will have a corresponding release, named [20250228_1](/releases/tag/20250228_1).
